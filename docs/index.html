Reclaim gigabytes
from your Mac, by hand.

hand-clean scans the well-known noisy paths on a macOS dev machine — Xcode DerivedData, iOS DeviceSupport, language caches, project build artifacts — shows them in a multi-select TUI, and lets you delete them safely (move-to-Trash by default).

curl -fsSL https://raw.githubusercontent.com/wanggang316/hand-clean/main/install.sh | bash

Installs to /usr/local/bin. Use VERSION=v0.1.0 or PREFIX=$HOME/.local to customize.

Features

Built for developers
who actually use their disk.

Interactive TUI

Bubble Tea–powered terminal UI. Multi-select with space, expand groups with enter, delete with d.

Move to Trash by default

Deletions are recoverable from the macOS Trash. Pass --rm only when you mean it.

Safety levels

Every path is tagged safe, review, or hold so risky deletes never sneak past you.

Dry run mode

hand-clean --dry-run prints exactly what would be deleted — no side effects, ever.

Project-aware

Scans ~/dev, ~/Projects, ~/Code, ~/workspace for node_modules, target, build, .venv, and a dozen more.

Fast & native

Concurrent du workers. Single static Go binary. No daemons. No telemetry.

Safety

Three signals, one decision.

Every scanned path is graded so you can power through obvious wins and pause on the rest.

safe

Regenerable cache.

Deleting costs only rebuild time. Auto-toggleable with A.

review

Project artifacts and large stores.

Restorable, but worth a glance — confirm you don't want to ship from this build.

hold

User data or live state.

Downloads, container data, signed archives. Confirm carefully — these are not regenerable.

Usage

Boring flags. Predictable behavior.

# Interactive scan + multi-select TUI (default).
hand-clean

# Preview only — never touches disk.
hand-clean --dry-run

# Delete directly with rm -rf (skip Trash, unrecoverable).
hand-clean --rm

# Hide items below 200 MiB.
hand-clean --min=200M

# Custom project roots.
hand-clean --roots=~/work,~/oss

# Skip the project artifact scan entirely.
hand-clean --no-projects
